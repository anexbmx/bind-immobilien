UI audit report

LLS Services website problems and practical UI adjustments

Audit of https://lls.services/ captured on 2026-05-28. Screenshots were taken at desktop 1280x720 and mobile 390x844.

Site: Fulfilment Lagerlogistik - LLS Services GmbH Language: German Page height: 9512px Images detected: 36

Quick Score

The site has a clear business category, but the first visit experience and mobile readability need immediate attention.

C-First impression: blocked by consent dialog and duplicated brand graphic.
CMobile UX: readable in parts, but text spacing and modal layout are heavy.
B-Content: relevant logistics service copy, but hierarchy needs tightening.
D+Accessibility: many meaningful images have empty alt text.

Main Problems

Prioritized by impact on conversion, readability, accessibility, and trust.

Cookie dialog blocks the site

High

The consent modal covers the homepage on desktop and nearly the whole mobile screen. Users cannot evaluate the offer before dealing with a long privacy prompt.

Adjustment: use a compact consent banner, shorten the first view, and keep the full preference explanation behind a secondary settings action.

Hero repeats the logo instead of selling the offer

High

The header already contains the logo, then the hero uses an oversized logo image as the main content. The actual value proposition is small and visually secondary.

Adjustment: replace the giant logo with a real headline such as "Fulfillment und Lagerlogistik in NRW" plus 2-3 proof points.

Hero contrast is weak

High

Black text sits over a busy warehouse photo with a bright wash. The text is readable in places, but it does not feel deliberate or premium.

Adjustment: add a darker green/black overlay, move text into a consistent left-aligned block, and keep the primary CTA high in the viewport.

Mobile body copy has awkward word spacing

High

The first mobile content section appears justified, creating large gaps between words. This makes the copy harder to read and less professional.

Adjustment: set mobile paragraphs to left aligned, 16-18px font size, 1.55 line-height, and a max line length around 36-42 characters.

CTA hierarchy is unclear

Medium

The hero shows "Leistungen" above "Angebot anfordern". The secondary action visually competes with the primary conversion action.

Adjustment: make "Angebot anfordern" the first and strongest CTA, then use "Leistungen ansehen" as a quieter text or outline button.

Navigation contains a visible spelling issue

Medium

The service link reads "Lagerlogostik E-Commerce" in navigation/footer data. That should be "Lagerlogistik E-Commerce".

Adjustment: correct the label everywhere, including menu, footer, page title, slug if possible, and internal link text.

Blocked media creates visual friction

Medium

The page has repeated "Inhalt entsperren" states for external media. Red blocked-content buttons interrupt the green brand system and add cognitive load.

Adjustment: provide a branded local poster image and only load external media after interaction. Avoid repeating blocked widgets in core conversion sections.

Images lack useful alt text

High

Captured page data showed many image elements with empty alt attributes, including brand and service visuals. This hurts accessibility and image SEO.

Adjustment: write descriptive alt text for meaningful images. Mark decorative background images as decorative instead of leaving important content unnamed.

Mobile header targets are tight

Medium

The mobile logo is very small and the phone/menu controls sit close to the viewport edge. Touch targets should be more forgiving.

Adjustment: use 44x44px minimum tap targets, slightly larger logo height, and consistent safe padding on left and right.

Contact flow feels detached

Medium

The main contact link points to an external SuperOffice form. That can reduce trust if users expect to stay on the LLS site.

Adjustment: add an on-page short contact form with phone, email, and response-time promise. External CRM can still handle submission behind the scenes.

Recommended UI Adjustments

These changes are scoped to improve conversion and credibility without requiring a full rebuild.

Hero

  • Use a real text H1, not a logo image as the main hero message.
  • Add a dark overlay on the warehouse image for stable contrast.
  • Use one primary CTA: "Angebot anfordern".
  • Add proof points: eigenes Lager, NRW, schnelle Umsetzung.

Mobile

  • Disable justified paragraph alignment on small screens.
  • Increase tap targets to at least 44px.
  • Reduce first-viewport logo size so value text appears sooner.
  • Keep one clear CTA visible without stacking too many elements.

Content & Trust

  • Correct "Lagerlogostik" to "Lagerlogistik".
  • Add alt text to service and brand images.
  • Use local fallback images for blocked videos/maps.
  • Bring the contact form on-site and show response expectations.

Suggested order for the next UI pass.

  • Replace the hero logo image with a text headline and proof-point row.
  • Apply dark overlay to hero background and test contrast on desktop/mobile.
  • Simplify cookie first view and verify it does not cover all meaningful content on mobile.
  • Fix mobile paragraph alignment and line length.
  • Correct spelling and navigation labels.
  • Add image alt text and review decorative images.
  • Replace repeated blocked media boxes with local posters or static previews.
  • Add an on-page contact section with phone, email, and short form.
